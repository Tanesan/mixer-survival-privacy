プライバシーポリシー — ミキサー・サバイバル

最終更新: 2026-08-11

「ミキサー・サバイバル」（以下、本アプリ）における利用者情報の取り扱いについて説明します。

本ポリシーの公開版は GitHub Pages で掲載しています（ストアの Privacy Policy URL にはそちらを設定します）。

公開版のソースは distribution/store/privacy.html です。

1. 収集しない情報

本アプリは、次の情報を一切収集しません。

  • 氏名、メールアドレス、電話番号などの連絡先
  • 位置情報
  • 連絡先リスト、写真、カメラ、マイク、その他の端末内データ
  • 広告識別子（IDFA / AAID）およびトラッキング目的の情報

本アプリにはアカウント登録、ログイン、広告、アプリ内課金はありません。

2. 端末内にのみ保存する情報

次の情報は利用者の端末内にのみ保存され、外部へ送信されません。

  • 最高記録（生存秒）
  • クリア済みレベル
  • チュートリアルの表示済みフラグ
  • 効果音 / BGM / 不具合レポートの設定

これらはアプリを削除すると消去されます。

3. 不具合（クラッシュ）レポート

本アプリはアプリの不具合を修正する目的で、Google 提供の Firebase Crashlytics を利用しています。

アプリが異常終了または例外を検出した場合に、次の情報が送信されます。

送信される情報目的
クラッシュのスタックトレース（プログラム内部の実行位置）不具合の原因特定
端末の機種、OS バージョン特定端末でのみ起きる不具合の特定
アプリのバージョン、ビルド番号どの版で発生したかの切り分け
Firebase installation ID（端末ごとの識別子）影響を受けた端末数の集計

プレイ内容、スコア、操作履歴、設定内容は送信しません。 上記の情報を利用者個人の特定に用いることはなく、

広告やトラッキングの目的にも使用しません。

送信の停止（オプトアウト）

アプリ内の 設定 →「不具合レポート」 をオフにすると、その時点で送信を停止します。

既定はオンです。オフにしても本アプリのすべての機能を通常どおり利用できます。

取り扱い事業者

  • Google LLC（Firebase Crashlytics）
  • Firebase のプライバシーとセキュリティ:
  • データの保持期間は Firebase Crashlytics の既定（クラッシュレポートは最長 90 日）に従います。

4. 第三者への提供

上記 Crashlytics を除き、利用者の情報を第三者へ提供することはありません。

法令に基づく開示請求があった場合を除き、情報を販売・共有しません。

5. 子どものプライバシー

本アプリは全年齢を対象としており、年齢を問わず上記以外の情報を収集しません。

不具合レポートも個人を特定する情報を含みません。

6. 利用者の権利

  • 端末内のデータは、アプリを削除することでいつでも消去できます。
  • 送信済みのクラッシュレポートの削除を希望される場合は、下記の連絡先までご連絡ください。

7. 本ポリシーの変更

内容を変更する場合は、本ページの更新日を改めたうえで掲載します。

収集する情報の種類を増やす変更を行う場合は、アプリ内で事前にお知らせします。
